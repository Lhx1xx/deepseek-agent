# 知识库目录

把你想让 AI 智能体「读懂」的私有资料放到这个目录，它就能基于这些资料回答你的问题（RAG 检索增强生成）。

## 支持的文件类型

- `.txt` 纯文本
- `.md` Markdown
- `.pdf` PDF 文档

## 使用方法

1. 把文件复制到本目录
2. 确保 Ollama 已启动，并已执行 `ollama pull nomic-embed-text`（只需一次）
3. 运行程序，向智能体提问时说明要查资料，例如：「根据我的知识库，XX 是什么？」

首次检索时会自动建立索引（向量化 + 缓存到磁盘），之后文件没变就直接读缓存，速度很快。

## 注意

- 文件修改后，索引会自动重建（通过文件修改时间判断）
- 隐藏文件（以 `.` 开头）会被忽略
- `.index_*` 开头的是缓存文件，不要手动编辑；想强制重建索引可删除它们
