# AI 智能体助手 —— 产品说明

## 产品简介

这是一个基于大语言模型（LLM）的 AI 智能体助手，能够调用多种工具自主完成用户的请求。用户用自然语言提问，智能体自己判断需要调用哪些工具、分几步完成，最终给出基于真实工具结果的回答。

## 核心功能

1. 文件读写：读取、写入、列出本地文件。
2. 网页搜索：抓取 Bing 搜索结果，获取最新外部信息。
3. 知识库检索（RAG）：基于用户本地文档的语义检索，回答私有资料相关问题。
4. 命令执行：运行 shell 命令，默认关闭，需要手动开启开关。

## 技术栈

- 编程语言：Python 3.11
- 大模型：DeepSeek（通过 OpenAI 兼容接口接入）
- 向量化模型：Ollama 运行 nomic-embed-text
- 界面：Gradio
- 检索算法：余弦相似度，基于 NumPy 实现

## 架构设计

采用 ReAct 式 Agent 循环：模型根据用户输入决定是否调用工具，执行工具后把结果回填进上下文，再让模型判断是否继续调用工具，循环直到产出最终答案。核心循环是手写实现，不依赖 LangChain 等框架，以便完全掌控工具调用流程。

## 安全设计

命令执行工具设置了默认关闭的安全开关，防止任意代码执行风险；Agent 设置了最大迭代轮数，防止死循环；工具执行报错会回传给模型，让模型自行修正或如实告知用户。

## 适用场景

适合作为个人知识助手、自动化办公助手，也可作为 AI 应用开发的学习项目，理解 LLM 智能体的底层工作原理。
